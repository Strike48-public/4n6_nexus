================================================================================
DEMO WORKFLOW
================================================================================

**Scenario 1: Quick Demo (Synthetic)**

1. Launch TUI:
   ```bash
   python3 demo_tui.py
   ```

2. Case Loader appears
   - Navigate with arrow keys
   - Click "🔴 02_ransomware" button

3. Analysis screen loads instantly (~2s)
   - Shows 3 findings (mass encryption, timestomping, persistence)
   - Self-correction counter: "Resolved 3×"
   - Reasoning: Multi-artifact correlation visible

4. Interact with findings:
   - Press 'd' to drill down
   - Press 'a' to approve
   - Press 'e' to export report

5. Switch scenarios:
   - Press 'c' to return to case loader
   - Try "⏱️ 03_timestomping" for different demo

**Scenario 2: Real Evidence Demo (M57-Jean)**

1. Launch TUI
2. Scroll to "📧 M57-Jean (Corporate Espionage)"
3. Click button
4. Notification: "Loading M57-Jean... (requires evidence mount)"
5. Analysis screen shows:
   - Case: M57-Jean
   - Evidence: nps-2008-jean.E01
   - Status: ● ANALYZING

**Scenario 3: Analysis Mode Selection**

1. Launch TUI
2. Scroll to "⚙️ ANALYSIS MODE"
3. Click "🚀 Quick Triage"
4. Notification: "Mode: Quick Triage selected"
5. (Future: actually filters detectors)

================================================================================
IMPLEMENTATION NOTES
================================================================================

**Technical approach:**
- Screen-based navigation (Textual's push_screen API)
- CaseLoaderScreen: scrollable vertical list with buttons
- AnalysisScreen: original four-panel layout
- State passed via constructor (case_name, evidence_type, mode)
- Dynamic subtitle updates based on selected case

**Button actions:**
- synthetic_ransomware → AnalysisScreen("02_ransomware", "synthetic", "quick")
- real_m57jean → AnalysisScreen("M57-Jean", "real", "full")
- mode_quick → Notify only (implementation TBD)

**Future enhancements:**
- Actually wire analysis mode to detector filtering
- Show progress bar during synthetic scenario loading
- Add custom detector selection screen (checkboxes)
- Load real scenario list from scenarios/real/ directory
- Remember last selected case (persist in ~/.sift/tui_prefs.json)
