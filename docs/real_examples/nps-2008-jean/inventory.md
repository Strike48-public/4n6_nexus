## Event Logs

`/WINDOWS/system32/config/`:

| File | Size |
|------|------|
| SecEvent.Evt | 65 536 bytes |
| AppEvent.Evt | 65 536 bytes |
| SysEvent.Evt | 196 608 bytes |

Event Log parsing path: `python-evtx` does NOT handle the legacy `.Evt` format. Use one of:

1. `python-evt` (pip package `python-evt`) - pure-Python.
2. SIFT's `evtxexport` from libevtx-utils - does handle the legacy format despite its name; OR
3. SleuthKit + `psort.py` via Plaso (if installed).

Path (2) will be tried first because it is a single-binary read-only CLI and matches the "prefer court-vetted CLI" rule in the top-level CLAUDE.md.

## Prefetch

`/WINDOWS/Prefetch` contains **130 `.pf` entries**. PECmd (already installed) parses XP-format prefetch without modification.

Noteworthy prefetch names visible in the first page:

- `AIM6.EXE` (AOL Instant Messenger 6)
- `FIREFOX.EXE`
- `EXPLORER.EXE`, `CMD.EXE`, `CONTROL.EXE`
- Multiple AOL installers (`AIMINST`, `AOLSOFTWARE`, `AOLDLMGR`, `AOLTBSERVER`)

AIM is a plausible exfil vector (file transfer over OSCAR). Firefox provides a secondary exfil vector via webmail.

## Target spreadsheet

Filename to hunt for: `m57plan.xlsx` (exercise slides) / `m57biz.xls` (what is actually on disk).

Hits under user dirs:

- `/Documents and Settings/Jean/Desktop/m57biz.xls` - the file itself

- `/Documents and Settings/Jean/Application Data/Microsoft/Office/Recent/m57biz.LNK` - Office MRU entry

These three hits are sufficient to prove custody on Jean's account. They are not by themselves sufficient to prove exfiltration, which is the actual question.
