DOWNLOAD NOTES
===============================================================================

1. All files use Expert Witness Format (.E01, .E02, .E03)
2. Large files may take significant time to download
3. Verify file integrity using MD5/SHA1/SHA256 hashes
4. Total download size: ~50-100 GB for complete scenario
5. Use wget or curl with resume capability for large files
6. Network captures may be split into multiple files

Example download command:
  wget -c https://downloads.digitalcorpora.org/corpora/scenarios/m57-patents/nps-2008-jean/nps-2008-jean.E01

Example with all files in a directory:
  wget -r -np -nc https://downloads.digitalcorpora.org/corpora/scenarios/m57-patents/nps-2008-jean/
