## Scenario Background

This is a comprehensive, multi-character corporate scenario involving intellectual property theft at the fictional company M57.biz, a small consulting and patent development firm.

### Company Overview

**M57.biz** is a small business specializing in:
- Patent development
- Technical consulting
- Research services

The company has approximately 5-10 employees with a mix of technical and administrative staff.

### The Incident

The scenario revolves around suspected intellectual property theft and corporate espionage. Evidence suggests that proprietary patent information may have been stolen and potentially sold to competitors or used for unauthorized purposes.

### Investigation Goals

1. Determine if intellectual property theft occurred
2. Identify the perpetrator(s)
3. Establish timeline of suspicious activities
4. Recover evidence of data exfiltration
5. Document the chain of custody for legal proceedings
6. Identify any co-conspirators or external parties involved

## Scenario Timeline

### Pre-Incident (2008-2009)
- M57.biz operating normally
- Patent development projects underway
- Normal employee activities

### Suspicious Activity Period (November-December 2009)
- Unusual file access patterns
- Large data transfers
- External communications with competitors
- USB device usage anomalies

### Discovery (December 2009)
- Management notices missing files
- IP audit reveals discrepancies
- Investigation initiated
- Forensic images captured

### Investigation Period
- Multi-device forensic acquisition
- Network traffic analysis
- Email and communication review
- Timeline reconstruction

## Key Investigation Elements

### Disk Forensics
- File system analysis (NTFS, FAT32)
- Deleted file recovery
- Timeline analysis (MAC times)
- Registry analysis
- Browser history and artifacts
- Email client data (Outlook, Thunderbird)
- Document metadata examination

### Memory Forensics
- Process analysis
- Network connections
- Encryption key recovery
- Malware detection
- Password extraction

### Network Forensics
- HTTP/HTTPS traffic analysis
- FTP transfers
- Email protocols (SMTP, POP3, IMAP)
- File transfer detection
- External IP correlation

### USB Device Forensics
- Device connection history
- Files copied to/from USB drives
- Deleted file recovery from portable media
- Volume shadow copies

### Email & Communication Analysis
- Email threads between employees
- External communications
- Attachment analysis
- Calendar entries and meetings
- Chat logs (IM, Skype)

### Data Exfiltration Indicators
- Cloud storage usage (Dropbox, Google Drive)
- Webmail access (Gmail, Yahoo)
- File compression and encryption
- Large file uploads
- Unusual outbound traffic

## Investigation Focus Areas

1. **Timeline Construction**
   - When did suspicious activity begin?
   - What files were accessed/modified?
   - When were external communications made?

2. **Data Identification**
   - Which patents/documents were compromised?
   - Where did the data go?
   - Who received the stolen information?

3. **Attribution**
   - Which employee(s) were responsible?
   - Was this an inside job or external attack?
   - Were there accomplices?

4. **Method Analysis**
   - How was data exfiltrated?
   - What tools were used?
   - Were anti-forensics techniques employed?

5. **Legal Evidence**
   - Chain of custody documentation
   - Hash verification of all evidence
   - Admissible artifacts for prosecution
