# Insider Threat Case (2022)

**Source:** DFIR.training
**Size:** ~6 GB
**Format:** E01 disk image
**OS:** Windows 10/11

## Scenario

Data exfiltration by authorized user.

## Investigation Focus

- USB device artifacts
- Cloud storage forensics (OneDrive, Dropbox)
- Data theft indicators
- User activity timeline

## Files Needed

Download from https://www.dfir.training/downloads/test-images:
- insider_system.E01 (or similar)

## Analysis Steps

1. Identify USB device connections
2. Analyze cloud storage artifacts
3. Review file access patterns
4. Document data exfiltration indicators
5. Build user activity timeline

4-5 hours for complete investigation
