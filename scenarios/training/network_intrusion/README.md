# Network Intrusion Challenge (2020)

**Source:** DFIR.training
**Size:** ~4 GB
**Format:** PCAP + memory dump
**OS:** Windows

## Scenario

Network-based attack with C2 communications.

## Investigation Focus

- PCAP analysis (protocol analysis, C2 detection)
- Network artifact correlation with system activity
- Malware network behavior
- Data exfiltration detection

## Files Needed

Download from https://www.dfir.training/downloads/test-images:
- network_capture.pcap
- memory.raw (or similar)

## Analysis Steps

1. Analyze PCAP for suspicious traffic
2. Identify C2 communications
3. Correlate with memory artifacts
4. Document network-based IOCs
5. Timeline network events

## Expected Time

3-4 hours for complete investigation
