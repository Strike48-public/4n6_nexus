# Ransomware Investigation (2021)

**Source:** DFIR.training
**Size:** ~8 GB
**Format:** E01 disk image
**OS:** Windows 10

## Scenario

Ransomware deployment via phishing attack.

## Investigation Focus

- Email forensics (phishing email analysis)
- Ransomware encryption analysis
- File system timeline
- Attribution indicators

## Files Needed

Download from https://www.dfir.training/downloads/test-images:
- ransomware_investigation.E01 (or similar)

## Analysis Steps

1. Mount E01 image
2. Extract email artifacts (PST/OST files)
3. Timeline file system events
4. Identify ransomware executable and behavior
5. Document IOCs and TTPs

## Expected Time

4-6 hours for complete investigation
