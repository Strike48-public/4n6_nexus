# DFIR.training Scenarios

This directory contains training scenarios from dfir.training.

## How to Download

1. Register at https://www.dfir.training (free)
2. Login and navigate to Downloads > Test Images
3. Download scenarios to their respective directories
4. Verify file integrity if checksums provided

## Priority Download Order

1. **Ransomware Investigation** (8 GB) - CRITICAL
   - Most common enterprise threat
   - Comprehensive analysis skills

2. **Blue Team IR Challenge** (10 GB) - HIGH
   - Full breach investigation workflow
   - Memory + disk correlation

3. **Insider Threat Case** (6 GB) - HIGH
   - Insider threat detection patterns
   - USB and cloud forensics

4. **Network Intrusion** (4 GB) - MEDIUM
   - Network forensics specialization
   - C2 detection skills

## Total Size

~28 GB for all four scenarios
